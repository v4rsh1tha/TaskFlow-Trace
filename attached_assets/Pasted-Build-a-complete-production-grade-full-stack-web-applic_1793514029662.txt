### 2. THE 6-STEP "HOW IT WORKS" FULL-STACK DIAGRAM SPECIFICATION
Every run must execute and record these exact 6 steps in order, matching the boxes in the attached image:
1. **`Input Received`** — Layer Badge: **`[PAGE -> SERVER]`** — *Browser sends messy notes payload to the Replit server.*
2. **`Validation`** — Layer Badge: **`[SERVER]`** — *Server validates note text, length, and request payload.*
3. **`AI Task Extraction`** — Layer Badge: **`[OUTSIDE SERVICE]`** — *Server calls the AI model (or fallback NLP service if AI fails/is unavailable) to extract tasks and deadlines.*
4. **`Prioritization & Scoring`** — Layer Badge: **`[SERVER]`** — *Server assigns priority (`High`/`Medium`/`Low`), calculates Confidence Score (`0–100%`), checks for duplicates, and maps task dependencies.*
5. **`Save Tasks`** — Layer Badge: **`[DATABASE]`** — *Saves extracted tasks and run events to PostgreSQL (with automatic retry backoff if a temporary DB drop occurs).*
6. **`Response Rendered`** — Layer Badge: **`[SERVER -> PAGE]`** — *Server streams the final structured tasks and telemetry back to the browser UI.*

- Clicking any of the 6 boxes on the diagram highlights it and displays that step's exact `Input JSON`, `Output JSON`, timestamp, and duration (`ms`) in the bottom `Payload` inspector.

### 3. SMART TASK INTELLIGENCE RULES
- **Strict Unspecified Deadline Rule:** Extract stated deadlines (`Today`, `Monday`, `Friday`), and whenever a task has NO deadline stated in the note (e.g., *"apply to five companies"*), mark its deadline as **`Unspecified`** with an Amber warning badge—never invent dates.
- **Confidence Score, Duplicate Detection & Missing Info:** Each extracted task displays a confidence percentage (`e.g., 94%`), flags duplicates against existing tasks, and highlights missing info (`Missing: Exact deadline`).
- **Inline Edit & Approval:** Users can edit any extracted task's title, priority, or deadline, mark tasks complete, or delete them.
